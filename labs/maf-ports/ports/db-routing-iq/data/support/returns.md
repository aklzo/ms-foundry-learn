# 返品・交換ポリシー(カスタマーサポート FAQ)

> このファイルは db-routing-iq ポートのサンプルコーパス(架空の会社
> 「アオゾラ電機」のサポート情報。2026-07 作成、ラボ内利用)。

直販サイトで購入した製品は、商品到着から 30 日以内であれば返品を申請
できる。未開封・未使用が原則だが、初期不良の場合は開封済みでも交換または
返金の対象になる。

返品手順: マイページの注文履歴から「返品申請」を選び、返送用ラベルを
印刷して同梱の上、指定の配送業者に集荷を依頼する。返送料は初期不良の
場合は当社負担、お客様都合の場合はお客様負担となる。

返金は商品の検品完了後、5〜10 営業日以内に購入時の決済手段へ行われる。
セール品・アウトレット品は返品対象外(初期不良を除く)。
