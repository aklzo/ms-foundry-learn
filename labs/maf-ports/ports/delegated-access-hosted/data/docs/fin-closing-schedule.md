# 月次決算スケジュール(経理部内規)

経理部の月次決算の段取り(架空の経理部内規・ラボ用。経理部員のみ閲覧可)。

| 営業日 | 作業 |
| --- | --- |
| 第 1〜3 営業日 | 売上・仕入の計上締め、経費精算の締め |
| 第 4 営業日 | 売掛金の消込と与信限度額に対する残高確認 |
| 第 5 営業日 | 仮締めと部門別損益の速報 |
| 第 7 営業日 | 本締め、経営会議への月次報告 |
