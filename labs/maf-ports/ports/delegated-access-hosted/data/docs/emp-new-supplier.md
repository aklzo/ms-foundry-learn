# 新規取引先の登録申請

新しい取引先と取引を始めるときの申請手順(架空の社内規程・ラボ用)。

1. 依頼部署が「取引先登録申請書」を作成し、会社概要・取引内容・想定取引額を記入する。
2. 購買部が反社会的勢力のチェックと相見積の妥当性を確認する。
3. 経理部が与信審査を行い、登録の可否と支払条件を決める。審査の基準は経理部の内規による。
4. 登録が完了すると取引先 ID(S- で始まる番号)が発行され、取引先マスタに載る。

支払条件(支払サイト)の変更は経理部の権限者だけが行う。変更を希望する場合は経理部へ依頼する。
