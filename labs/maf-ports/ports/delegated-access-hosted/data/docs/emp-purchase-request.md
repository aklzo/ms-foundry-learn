# 購買申請の手順

物品・役務を購入するときの社内手続き(架空の社内規程・ラボ用)。

1. 購買システムで購買申請を作成し、上長の承認を受ける。
2. 10 万円以上の購買は 2 社以上の見積を添付する。
3. 発注は購買部が行う。社員が取引先へ直接発注してはならない。
4. 検収は納品から 5 営業日以内に購買システムで登録する。支払は経理部が支払条件に従って行う。

取引先マスタ(取引先 ID・名称・支払サイト)は社内エージェントの取引先ツールで参照できる。
