# 支払条件変更の承認基準(経理部内規)

取引先マスタの支払サイトを変更するときの基準(架空の経理部内規・ラボ用。経理部員のみ閲覧可)。

- 支払サイトの変更は Suppliers.Write ロールを持つ経理部員が、社内エージェントの取引先更新ツールで行う。
  更新は監査記録(実行者・変更前後・日時)に自動で残る。
- 支払サイトの上限は 120 日。中小受託取引の対象先は 60 日以内とする。
- 支払サイトを延ばす変更は、取引先の書面による同意を得てから行う。
- 与信限度額を超えている取引先の支払サイト短縮は、経理部長の承認を得る。
