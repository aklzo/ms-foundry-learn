# 情報セキュリティ基本方針

全社員が守る情報セキュリティの基本ルール(架空の社内規程・ラボ用)。

## サインインと多要素認証

- 社内システムへのサインインは Microsoft Entra ID の多要素認証(MFA)を必須とする。
- パスワードやワンタイムコードを他人に教えない。ヘルプデスクも尋ねることはない。

## 情報の持ち出し

- 社外秘の文書を個人のクラウドストレージや個人メールへ転送してはならない。
- 生成 AI サービスへの入力は、会社が承認したサービス(社内エージェント等)に限る。

## インシデントの報告

- 端末の紛失・不審なメールの開封に気づいたら、30 分以内に情報システム部へ報告する。
