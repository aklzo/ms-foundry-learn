使い方

  • 設計レビュー前: 採用する構成のシナリオ(01)が参照する P-ID を列挙し、「対処」欄が設計・見積もりに入っているかを確認する
  • 提案書のリスク欄: 症状と対処をそのまま転記できる粒度にしてある。出典 URL を添えると顧客説明の根拠になる
  • 障害切り分け: 症状の言葉(エラー文言)で検索する。「デプロイは成功するが実行だけ失敗」「読めるのに実行できない」「ポータルは見えるのに Playground が死ぬ」のような誤診しやすい断面を優先して収録した
