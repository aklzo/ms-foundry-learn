## 概要

旧 Azure AI Services は「**Foundry Tools**」に正式改称済み(ページタイトル「What are Foundry Tools?」。各サービスも「Azure Speech in Foundry Tools」等に改称)。ただし**ドキュメント URL は `/azure/ai-services/` 配下に残存**している。

**リソースモデル**: Foundry リソース(kind = `AIServices`)1つで、**1エンドポイント・1キーにより Azure OpenAI + Foundry Tools に到達可能**。バンドル対象として公式表に明記されているのは Content Safety / Document Intelligence / Language / Speech / Translator / Agent Service / Model Inference。Content Understanding も Foundry リソースの一部として利用可能と明記。**例外は Face(個別リソース+limited access 申請制)と Custom Translator(専用ポータル)**。

## プレイグラウンド提供状況(Foundry 新ポータル)

- 中核プレイグラウンドは **Model / Agents / Images(GA)/ Video(プレビュー)** の4種( https://learn.microsoft.com/en-us/azure/foundry/concepts/concept-playgrounds 2026-07-28 版・GA 一覧表 2026-08-14 版)。
- Foundry Tools 系: Speech(STT/TTS/アバター/Voice Live)は新ポータル提供で **GA 一覧表に「AI services speech playgrounds = GA」**。Language は Foundry でノーコード試用可(Document PII playground は GA 明記。2026-06 に PII 3 種・言語検出・TA4H のプレイグラウンドが新ポータルに追加)。Content Understanding は新ポータルに Content Understanding プレイグラウンド(**`2026-06-01-preview` API のみ**、prebuilt の一部)。Translator は classic ポータル表記(overview)だが What's new は新ポータルのテキスト/ドキュメント翻訳プレイグラウンドを記載、Adaptive LLM は新ポータル GA。Document Intelligence と Face は Foundry 外の専用 Studio(DI Studio / Vision Studio)のまま。
- GA 一覧表(2026-08-14 版。2026-09-23 更新版でも同一)の「Unsupported at GA(classic 必須)」に列挙されている Foundry Tools 関連: **Audio playground・AI service fine-tuning(Speech / Vision custom model training)・Content Understanding・video playground の prebuilt prompts**。ただし CU と custom speech fine-tuning は各サービス側ドキュメントが Foundry(新)対応を記述しており**表と不一致**(上表参照)。CU・評価・エージェント等は API キー不可で Entra 必須。

## 補足ノート(SI 判断に効く要点)

- **世代交代が進行中**: Image Analysis→Content Understanding / Foundry Models、Document Intelligence→Content Understanding と併存(決定論的抽出は DI、LLM 分析は CU)、Language の CLU / 要約系は「legacy」化(エージェント時代は MCP server+プレビルトエージェントへ)、Translator は NMT v3→LLM ベース `2026-06-06` へ。
- **エージェント統合の形**: 各 Foundry Tool は「MCP server / Tool Catalog / プレビルトエージェント」経由で Foundry Agent Service に接続する方向(Speech MCP server、Language MCP server、Voice Live のエージェント統合)。**Speech MCP server は Agent Service Enterprise tier 必須・ネットワーク分離 Foundry 非対応**、Language MCP server はプレビュー(`2025-11-15-preview`)で閉域構成に制約あり(いずれも 2026 年版ドキュメントで明記)。
- **standard setup(BYO ストレージ)**のバリアントが Speech / Language / Vision / Content Understanding 向けにあり(Speech / Language の Storage Account オプションはプレビュー)。
- **Voice Live のステータス(2026-09-07 に再更新)**: 2026-07-30 時点では GA 一覧表の「Build > Agents — Voice Live = Preview」を根拠に「Preview 扱いが安全」としたが、[Speech の What's new(Voice Live タブ)](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/releasenotes?pivots=voice-live)で **Voice Live API 単体は 2025-11 に GA、`2026-04-10` で Agent Service 統合・MCP 統合・Java/JS SDK が GA、`2026-07-15` API も GA** と明記されているのを確認した。GA 一覧表の Preview は **Foundry ポータルの Agents サーフェス(エージェント作成画面で Voice Live を付ける体験)**のステータスで、Build 2026 公式ブログ(2026-06-02)は prompt agents 向けは GA・hosted agents × Voice Live はパブリックプレビューと書いている。**読み方: 「Voice Live API(WebSocket・SDK 直叩き)は GA。Foundry Agents 経由はサーフェス次第で、hosted agents 経由と WebRTC は Preview」**。GA 一覧表(最終権威)と Speech 側の表記が食い違うため、SLA を論点にする案件では Microsoft への個別確認が引き続き必要。
