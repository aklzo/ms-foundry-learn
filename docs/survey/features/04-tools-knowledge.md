## 概要

Foundry Agent Service のツール群とナレッジ(RAG)機構を扱う。**カタログとコアツール基盤は GA、個別ツールは一部プレビュー**という構図は変わらず、GA 一覧表(2026-08-14 版)に「Discover > Tools = GA」「Build > Tools = GA (check label on individual tools in the catalog)」「Build > Toolboxes = GA」と明記(出典: https://learn.microsoft.com/en-us/azure/foundry/concepts/general-availability )。

**2026-09-26 注記:** GA 一覧表(ms.date 2026-08-14 のまま、2026-09-23 更新版)のツール関連行は変化なし。一方で公式ブログ側が動いた: devblogs 月次まとめ 7・8 月合併号(2026-09-09 公開)が **「Toolboxes — generally available (GA)」** と明言し、Skills と Tool search は「both in public preview」と記載。さらに Azure 公式ブログ(2026-09-24「Microsoft Foundry expands model choice with voice agents and continuous optimization」)は **Tool search in Toolboxes = GA、Agent-to-Agent (A2A) = GA**、「Toolboxes are already generally available for hosted agents and are now expanding to prompt agents in public preview」と書いている(出典: https://devblogs.microsoft.com/foundry/whats-new-in-microsoft-foundry-july-august-2026/ ・ https://azure.microsoft.com/en-us/blog/ship-agents-faster-with-expanded-model-choice-voice-agents-and-continuous-optimization/ )。A2A の GA は Learn(移行ガイド・A2A ページ 2026-09-11 版)でも確認できるが、Tool search の GA は Learn 側(toolbox-overview 2026-07-28 版「Tool search (preview)」)に未反映で表記揺れ(下表参照)。

**2026-09-07 注記:** 初版が引用した旧「ツールカタログ」概念ページ(/azure/foundry/agents/concepts/tool-catalog)は **/azure/foundry/agents/concepts/toolbox-overview(「What is Toolbox in Foundry?」、2026-07-28 版)へ 301 リダイレクト**され、「The Foundry tool catalog and the core tools framework are generally available...」の文言はリダイレクト先に存在しない。ドキュメント側でツール別の GA / Public Preview ラベルを最も明示的に列挙しているのは**移行ガイドの「Agent tool availability」表**(classic → 新の対応表、2026-08-05 版: https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/migrate#agent-tool-availability )で、下表のラベルはこれと各ツールページのタイトル「(preview)」表記・TOC ラベルに基づく。

カタログのエントリ種別は Remote MCP server / Local MCP server / Custom(Logic Apps コネクタから変換した MCP サーバー)の3種(旧 tool-catalog ページ時点の記載)。**2026-09-07 時点**のドキュメント構成は「Toolboxes > Add tools and skills」配下に各ツールが並び、カタログ由来の機構として **Managed MCP servers(コネクタ名前空間、1,000+ コネクタ、プレビュー)**・**Private tool catalog(Azure API Center ベース、プレビュー)**・**Private skill catalog(プレビュー)** の 3 つが個別ページ化されている(下表の追加行と補足ノート (g) 参照)。ポータル操作は新ポータルの Build > Tools(Toolbox は「Build & customize > Toolboxes」の記載もあり)。

## 補足ノート(SI 判断に効く要点)

**(a) Deep Research の廃止と後継**
「Deep Research をツールとして使う」構成は今後組めない。web-search ページが「This approach replaces the deprecated Deep Research tool」と明言し、`o3-deep-research` モデル + Web search ツール(Responses API)への移行コードを掲載。2026-08-19 版では **`WebSearchPreviewTool`(`web_search_preview`)を prompt agent に直付け**する例に更新され、「Don't route web search through a toolbox for deep research」と明記(toolbox 経由では不可)。
**2026-09-26 追記:** その `o3-deep-research` モデル自体が **2026-11-19 リタイア予定**(リタイア表 2026-09-21 版で Deprecated、後継 gpt-5.6-sol)。classic の Deep Research ページ(2026-09-20 更新)も「モデルのリタイア時にツールも廃止、最新 Agents GA API + 最新 GPT モデル + web search を推奨」に更新された。**新規案件で deep research 相当を組むなら、o3-deep-research 前提の設計は避け、最新 GPT 系 + Web search(+ MCP)で多段リサーチを組む前提にする。**出典: https://learn.microsoft.com/en-us/azure/foundry-classic/agents/how-to/tools-classic/deep-research ・ https://learn.microsoft.com/en-us/azure/foundry/openai/concepts/model-retirement-schedule

**(b) Web search と Grounding with Bing の関係**
Web search(GA)が推奨経路で、Bing リソース接続不要のシンプル構成。市場フィルタ等の細かい制御が要るときのみ Grounding with Bing Search(GA)/ Bing Custom Search(プレビュー)。**いずれも DPA 対象外・コンプライアンス境界外へのデータ送信・別課金**という制約は共通で、規制業種の SI では要注意。web-overview(2026-04-08 版)は「both Web Search and Grounding with Bing Search are GA options on the new agents API」と明示し、比較表で Stage = GA / GA。閉域環境でも両者は「対応」だが **Public endpoint 経由**(configure-private-link 2026-08-14 版)。

**(c) Toolbox は GA(2026-07-30 に確定)**
初版では「明確な GA 宣言が確認できない」としていたが、[GA 一覧表](https://learn.microsoft.com/en-us/azure/foundry/concepts/general-availability)に **「Build > Toolboxes = GA」** と明記されているのを確認した。ツールカタログ表にも preview ラベルはない。初版時点では **REST/MCP の検証例に `Foundry-Features: Toolboxes=V1Preview` ヘッダーが残り、Python SDK も `client.beta.toolboxes` 名前空間**という実装上のねじれがあった。
**2026-09-07 更新:** 2026-08-26 版の toolbox ページでは **`Toolboxes=V1Preview` ヘッダーは消え、Python SDK も `project.toolboxes.create_version`(非 beta)**に整理された。残るねじれは (1) `Foundry-Features: Skills=V1Preview` ヘッダー(skills はプレビューなので整合)、(2) .NET SDK が preview(2.1.0-beta.4)、(3) Java SDK に toolbox 作成 API がない、(4) **公式ブログ(2026-06-02 Build 特集・2026-06-03 Toolbox 記事)が「Toolboxes in Foundry is in public preview」と書いている**こと。GA 一覧表(2026-08-14 版)を最終権威として GA と扱うが、提案書では「GA 一覧表上は GA、ブログ表記に揺れ」と注記するのが安全。
**2026-09-26 更新:** (4) のブログ表記の揺れは、devblogs 月次まとめ 7・8 月合併号(2026-09-09)が「Take tool authentication out of agent code with Toolboxes — generally available (GA)」と明言し、Python / JS `azure-ai-projects` 2.3.0 で toolbox 操作が beta 外に出たことも記載したため**解消**。残る注意点は、Azure ブログ(2026-09-24)の「hosted agents 向けは GA、**prompt agents への拡張はパブリックプレビュー**」という書き分けで、prompt agent から toolbox を MCP ツールとして使う構成を本番提案する場合はこの点を確認する(Learn の toolbox ページにはこの区別の記載なし)。

なお **hosted agent はエージェント定義にツールを直付けできず、Toolbox 経由が前提**になる([03-agent-service](./03-agent-service.md))。コードファーストを選ぶ案件では Toolbox が必須要素になる。各ツールページ(2026-08 版)も「Consider adding this tool using a toolbox」の Tip と Prompt agents / Hosted agents の 2 タブ構成(hosted 側は MAF の `FoundryChatClient` + `FoundryToolbox`)に統一された。

**(c-3) Toolbox の閉域化(2026-08 新規ページ)**
[Network isolation for a toolbox](https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/tools/toolbox-network-isolation)(2026-08-03 版)が新設。**toolbox 自体はネットワークリソースを持たず、ホストするプロジェクトの網構成に従う**。ツール別の経路: MCP / OpenAPI / A2A = VNet サブネット経由、Azure AI Search / File search = private endpoint 経由、Code interpreter = Microsoft backbone、Web search = 対応(Microsoft 管理の public endpoint)、Skills = 内包ツール依存、**Fabric IQ = Partial、Work IQ / Browser automation = 非対応**、Tool search = N/A。Basic は `11-private-network-basic-vnet`、Standard は `15-private-network-standard-agent-setup` テンプレートが起点。configure-private-link(2026-08-14 版)の「Agent tools with network isolation」表も同趣旨で、追加で **Function Calling = backbone、Bing / SharePoint = public endpoint、Azure Functions = VNet サブネット、Foundry IQ = Via MCP、Fabric Data Agent / Logic Apps / Computer Use / Image Generation = 非対応**。閉域案件のツール選定はこの 2 表が一次情報。
**2026-09-26 追記:** (1) **Skills が private networking に対応** — skills ページ(2026-09-18 版)から「Skills don't support private networking(Skills API は private endpoint 非対応)」の Limitations 節が削除され、「Skills support private networking」と virtual-networks ページへの誘導に置き換わった(閉域プロジェクトでもスキルの作成・管理・ダウンロードが可能に)。(2) **Work IQ** は work-iq ページ側で「BYO VNet outbound 構成では data proxy 経由、宛先は public HTTPS のまま」と説明が追加され、toolbox-network-isolation 表の「Not supported」と読み方が揃っていない(上表の Work IQ 行・要確認)。toolbox-network-isolation(2026-08-03 版)と configure-private-link(2026-08-14 版)の表自体は変化なし。

**(c-2) ⚠ Azure OpenAI On Your Data は非推奨で 2026-10-14 リタイア**
初版は Azure Architecture Center の Secure Multitenant RAG 記事の Important(「**Azure OpenAI On Your Data is deprecated and approaching retirement.** We recommend that you migrate ... to **Foundry Agent Service** with **Foundry IQ** ...」)を出典にしていたが、**2026-09-07 再確認:** 同記事(2026-08-19 版)からはこの callout が削除されている。一方、一次情報である On Your Data のページ(foundry-classic/openai/concepts/use-your-data、2026-06-24 更新)に「Azure OpenAI On Your Data is deprecated and approaching retirement. **The service will be retired on October 14, 2026**」と明記され、リタイア日が確定した(初版の「具体的なリタイア日は未公表」を更新)。
**含意:** 「オーケストレーターを挟まず、モデルが直接データストアを読む」構成は新規設計で選べない。下記(d)の3層はいずれもオーケストレーター型(エージェントまたは自前アプリ)を前提にする。既存の On Your Data ベースの提案書・PoC は棚卸しが必要で、**移行先は Foundry Agent Service + Foundry IQ(または AI Search ツール / File search)**。
出典: https://learn.microsoft.com/en-us/azure/foundry-classic/openai/concepts/use-your-data (旧出典: https://learn.microsoft.com/en-us/azure/architecture/ai-ml/guide/secure-multitenant-rag — 2026-08-19 版では該当文言なし)。**2026-09-26 再確認:** use-your-data ページは 2026-09-10 版に更新(Assistants API への言及削除等)されたが、「The service will be retired on October 14, 2026」の記載は変化なし(残り 3 週間を切った)。

**(d) ナレッジ(RAG)の3層構造**
1. **File search + ベクトルストア**(GA)— 手軽なマネージド RAG。1ストア/エージェント制限あり。
2. **Azure AI Search ツール**(GA)— 既存インデックス直結。1インデックス制限。
3. **Foundry IQ knowledge bases**(**KB 本体と主要ナレッジソースは API で GA(2026-04-01)、ポータルとリッチ機能はプレビュー** = GA 一覧表の「Partial GA」)— マルチソース+agentic retrieval+ACL/Purview 対応の上位層。接続は MCP 経由で、**Foundry Agent Service 以外(Microsoft Agent Framework、カスタムアプリ)からも同じ KB を利用可能** — MAF / LangGraph 比較の観点では、ナレッジ層をエージェントフレームワークから切り離せるのが設計上のポイント。

**(e) IQ ファミリーの整理**
Foundry IQ = エンタープライズデータのナレッジ層(Partial GA)、Fabric IQ = Fabric の分析データ層(プレビュー)、Work IQ = M365 のコラボレーション文脈層(プレビュー)。3つは独立だが併用可能。Foundry IQ は他 2 つを**ナレッジソースとして取り込む**方向にも拡張中(Work IQ / Fabric IQ ナレッジソースはプレビュー。ブログ 2026-06-02、Azure AI Search What's new 2026年8月)。

**(f) サーフェス全般の傾向**
ツール個別ページの Usage support 表は「Python / C# / JS / Java SDK + REST + basic/standard setup」形式で、**Azure CLI 列は存在しない**。Work IQ・Fabric IQ 接続は Java SDK 非対応、Foundry IQ 接続は C#/JS SDK も未対応(Python + REST のみ)という偏りがある。**2026-09-07 追記:** この偏りは 2026-08〜09 版でも継続(Fabric IQ・Work IQ の Java = 「—」、Foundry IQ 接続は Python + REST のみ)。A2A は Java 含め全 SDK 対応。Toolbox 作成 API は Java SDK 未提供(Code Interpreter / File Search / Custom CI の Java 節で明記)。.NET SDK は各ツールページで「currently in preview」の注記が付く。**2026-09-26 追記:** 2026-09-11 に Foundry agents の how-to 群へ C# 例を追加する更新(connectors・foundry-iq-connect 等)が入り、Foundry IQ 接続ページは Usage support 表(C# =「-」)と本文(.NET 例あり)が食い違う状態。A2A の GA 型を使う .NET は `Azure.AI.Projects` 3.0.0-beta.2 系のプレリリース版が必要。

**(g) Skills / Private catalog 系(2026-08 新規)— hosted agent 側の詳細は [03-agent-service](./03-agent-service.md)**
Skills(プレビュー)は SKILL.md をバージョン管理付き(不変バージョン)で Foundry に保存し、**toolbox に MCP Resources として添付**するか **hosted agent に直接ダウンロード**して使う機構。toolbox 側の扱いは本ページ、hosted agent 側の利用は 03 を参照。Private skill catalog(プレビュー)・Private tool catalog(プレビュー)はいずれも **Azure API Center** に組織限定のスキル / MCP サーバーを登録し、開発者に `Azure API Center Data Reader` を付与して Foundry の **Build > Tools > Skills > Browse skills**(スキル。カタログは独立項目ではなく **Registry フィルタに API Center 名**で出る)/ Build > Tools(ツール)から発見させる仕組み(ロール反映は最大 24 時間)。**2026-09-26 更新(private-skill-catalog 2026-09-14 版):** ポータル導線が旧「Build > Skills」から上記に変更。ロールは **API Center リソース(または親 RG / サブスクリプション)スコープ**で付与する必要があり、Foundry プロジェクトスコープの付与では API Center のカタログデータは読めないと明記。Skills 自体は 2026-09-18 版で private networking 対応(補足ノート (c-3))。スキルの「Allowed tools」がガバナンス境界。出典: https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/tools/skills ・ https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/private-skill-catalog ・ https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/private-tool-catalog
