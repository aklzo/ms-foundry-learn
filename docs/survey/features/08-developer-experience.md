## 概要

API は「**推論系 = v1 API(月次 `api-version` 廃止、OpenAI SDK 直結)**」と「**プロジェクト操作系 = Foundry SDK(`azure-ai-projects` 2.x)+ Microsoft Foundry REST API(v1 / v1-preview)**」の二層構造に整理された。SDK overview では接続先として Foundry SDK(`services.ai.azure.com/api/projects/...`)、OpenAI SDK(`/openai/v1`)、**Anthropic SDK**(`services.ai.azure.com/anthropic`)、Agent Framework、**Foundry Tools SDKs**(Vision / Speech 等のツール別エンドポイント)の5系統が明示されている(出典: https://learn.microsoft.com/en-us/azure/foundry/how-to/develop/sdk-overview 、2026-08-05 版。Foundry SDK は「thin-client SDK」と位置づけられ、Agent Framework の `foundry` パッケージはこれに依存する構図)。REST の横断リファレンスは https://ai.azure.com/api-reference/ (Foundry ネイティブ系は `api-version=v1`、OpenAI 互換系は api-version 不要、プレビュー機能は `Foundry-Features` ヘッダーで opt-in)。

## 補足ノート(SI 判断に効く要点)

1. **SDK パリティ**: 統合プロジェクトクライアント 2.x は Python (2.6.0) / .NET (2.0.1、プレリリースは 3.0.0-beta.2) / JS (2.6.0) / Java (2.4.0) の4言語すべて GA。Python が最も先行(JS は 2026-09-04 に Python と同日 2.6.0)。
2. **`azure-ai-inference` は 2026-08-26 に廃止済(期限到来)**。一度も GA せず beta のまま終了し、全言語で OpenAI SDK + v1 API へ移行する構図。既存資産の棚卸しが必要 — ただしレジストリにはパッケージが残り deprecated フラグも付いていない(2026-09-07 時点)ので、`pip install` が通ることを「まだ使える」と誤認しないこと。
3. **CLI は3系統に分裂**: (a) `az cognitiveservices`(リソース/プロジェクト/デプロイ管理、GA)、(b) azd の Foundry 拡張群(エージェント開発ライフサイクル、プレビュー)、(c) `az ml`(classic ハブ専用に格下げ)。**独立した `az foundry` コマンド群は存在しない** — 「Foundry の CLI」は azd 側に寄っている(2026-09-07 再確認: `az foundry` は依然なし、`az cognitiveservices agent` は Preview で現存、azd Foundry 拡張群は Beta)。
4. **MAF が Foundry ネイティブのコードファースト経路として GA**。ビジュアル Workflows 廃止(2026-12-01)の公式移行先でもあり、「portal(prompt agents)vs MAF(コードファースト)vs LangGraph(サードパーティ、hosted agents として持ち込み可)」という技術選定の3経路が明確化した。
5. **`azure-ai-inference` のリタイア日は 2026-08-26 で確定(2026-07-30 に一次情報で再確認)**。supported-languages ページの Important に「Azure AI Inference beta SDK is deprecated and will be retired on **August 26, 2026**. Switch to the generally available OpenAI/v1 API with a stable OpenAI SDK.」と明記され、**同ページに他の日付は存在しない**。初版が「揺れ」として記録した 2026-05-30 説は検索結果由来で、公式ページには根拠がなかった。**2026-09-07 追記: 同ページは「retired on August 26, 2026」(過去形)に更新済み**で、揺れは完全に決着。
6. **パッケージ版を 2026-07-30 にレジストリで再確認した結果**: `azure-ai-projects` 2.4.0(Production/Stable)/ `azure-ai-agents` 1.1.0(同)/ `azure-ai-inference` 1.0.0b9(Beta)/ `agent-framework` 1.12.1(同)/ npm `@azure/ai-projects` latest 2.3.1 / NuGet `Azure.AI.Projects` は安定版 2.0.1 + プレリリース 2.1.0-beta.4 — **いずれも初版の記載どおり**。`azure-ai-evaluation` のみ 1.18.2 → 1.18.3 に進んでいた。
7. **パッケージ版を 2026-09-07 に再確認した結果**: `azure-ai-projects` 2.6.0(2026-09-04)/ `azure-ai-evaluation` 1.18.5(2026-09-04)/ `openai` 3.8.0(2026-09-03)/ `agent-framework` 1.17.0(2026-09-03)/ npm `@azure/ai-projects` 2.6.0(2026-09-04)/ NuGet `Azure.AI.Projects` 2.0.1 + 3.0.0-beta.2 / Maven 2.4.0(2026-08-19)。変化なし: `azure-ai-agents` 1.1.0、`azure-ai-inference` 1.0.0b9(廃止後も残置)。
8. **`openai` 3.x への追従が必須化**: `azure-ai-projects` 2.5.0(2026-08-20)が `openai>=3.0.0`(httpx2)と Python 3.10+ を要求。`openai` 2.x や Python 3.9 で固定している既存資産は、projects SDK を上げるときに同時に上げる必要がある(docs の install-cli-sdk は「Python 3.9 が最小」と記載が残っており不整合)。
9. **MAF .NET の Foundry コネクタが preview 系列に戻っている**: コア `Microsoft.Agents.AI` は stable 継続(1.20.0)だが、`Microsoft.Agents.AI.Foundry` は 1.5.0(2026-05-08)以降 preview のみで docs も `--prerelease` を指示。.NET で Foundry 直結を本番採用する場合は stable 1.5.0 に固定するか preview を許容するかの判断が必要(Python は `agent-framework-foundry` 1.12.0 stable で問題なし)。hosting 系パッケージは両言語とも prerelease。
10. **「コーディングエージェントに Foundry を操作させる」第4のサーフェスが公式化**: Foundry Skill(GitHub Copilot / Claude Code / Codex)+ Foundry MCP Server + Foundry Canvas + DevPack が 2026-05〜08 に揃い、ポータル / SDK / azd に並ぶ経路になった。ただし Foundry MCP Server は preview・ネットワーク分離不可・EU/US 処理のため、閉域・データ所在地要件のある案件では使えない(Skill 自体は az / azd 経由で動くため MCP Server なしでも機能する)。
