概要

Foundry Agent Service のツール群とナレッジ(RAG)機構を扱う。カタログとコアツール基盤は GA、個別ツールは一部プレビューという構図は変わらず、GA 一覧表(2026-08-14 版)に「Discover > Tools = GA」「Build > Tools = GA (check label on individual tools in the catalog)」「Build > Toolboxes = GA」と明記(出典: general-availability )。

2026-09-26 注記: GA 一覧表(ms.date 2026-08-14 のまま、2026-09-23 更新版)のツール関連行は変化なし。一方で公式ブログ側が動いた: devblogs 月次まとめ 7・8 月合併号(2026-09-09 公開)が 「Toolboxes — generally available (GA)」 と明言し、Skills と Tool search は「both in public preview」と記載。さらに Azure 公式ブログ(2026-09-24「Microsoft Foundry expands model choice with voice agents and continuous optimization」)は Tool search in Toolboxes = GA、Agent-to-Agent (A2A) = GA、「Toolboxes are already generally available for hosted agents and are now expanding to prompt agents in public preview」と書いている(出典: whats-new-in-microsoft-foundry-july-august-2026 ・ ship-agents-faster-with-expanded-model-choice-voice-agents-and-continuous-optimization )。A2A の GA は Learn(移行ガイド・A2A ページ 2026-09-11 版)でも確認できるが、Tool search の GA は Learn 側(toolbox-overview 2026-07-28 版「Tool search (preview)」)に未反映で表記揺れ(下表参照)。

2026-09-07 注記: 初版が引用した旧「ツールカタログ」概念ページ(/azure/foundry/agents/concepts/tool-catalog)は /azure/foundry/agents/concepts/toolbox-overview(「What is Toolbox in Foundry?」、2026-07-28 版)へ 301 リダイレクトされ、「The Foundry tool catalog and the core tools framework are generally available...」の文言はリダイレクト先に存在しない。ドキュメント側でツール別の GA / Public Preview ラベルを最も明示的に列挙しているのは移行ガイドの「Agent tool availability」表(classic → 新の対応表、2026-08-05 版: migrate )で、下表のラベルはこれと各ツールページのタイトル「(preview)」表記・TOC ラベルに基づく。

カタログのエントリ種別は Remote MCP server / Local MCP server / Custom(Logic Apps コネクタから変換した MCP サーバー)の3種(旧 tool-catalog ページ時点の記載)。2026-09-07 時点のドキュメント構成は「Toolboxes > Add tools and skills」配下に各ツールが並び、カタログ由来の機構として Managed MCP servers(コネクタ名前空間、1,000+ コネクタ、プレビュー)・Private tool catalog(Azure API Center ベース、プレビュー)・Private skill catalog(プレビュー) の 3 つが個別ページ化されている(下表の追加行と補足ノート (g) 参照)。ポータル操作は新ポータルの Build > Tools(Toolbox は「Build & customize > Toolboxes」の記載もあり)。
