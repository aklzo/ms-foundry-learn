本ドキュメント群は SI の技術選定・アーキテクチャ選定基準の構築を目的に、Microsoft Foundry の機能と GA / プレビューのステータスを整理したものです。定期更新を前提としています(更新手順は本ページ末尾)。

関連ドキュメント: 本ページ群は「その機能は使えるのか」を引くためのもの。「どう組むか」は アーキテクチャ設計ガイド を参照。

このドキュメント群について

  • 正(マスター)は Markdown(生成 AI 用)。人間用 HTML は共有ビルダー docs/survey/tools/md2html.py で html/ 配下に自動生成します。HTML を直接編集しないでください。
  • 各機能について「全体ステータス」に加え、サーフェス別(ポータル / Azure CLI / Python SDK / REST)の対応状況を、公式ドキュメントに記載がある範囲で記録しています。記載がない場合は「記載なし」、確認できなかった場合は「要確認」と正直に書きます(推測でステータスを書かない)。
  • すべての行に出典(learn.microsoft.com 等の公式 URL)を付けています。

ステータス凡例

表記 意味
GA 一般提供(General Availability)。SLA・サポート対象
パブリックプレビュー 公開プレビュー。SLA なし・仕様変更あり得る。本番利用は原則非推奨
限定プレビュー 申請制・招待制のプレビュー(limited access / gated)
非推奨 Deprecated。廃止日が予告されている(新規利用を避ける)
廃止 Retired。利用不可
要確認 公式ページ上にライフサイクル明記が見つからなかったもの(確認した URL を併記)

注意: 公式ドキュメント間でステータス表記が揺れている機能があります(例: Toolbox〈GA 一覧表=GA / 公式ブログ=public preview〉、Voice Live〈API 単体=GA / Agents 経由=Preview〉、Content Understanding〈GA 一覧表=classic 必須 / 新ポータルにプレイグラウンドあり〉、Trace Replay〈GA 一覧表=GA / 記事見出し=preview〉、Agent optimizer〈GA 一覧表=Limited preview / 記事=preview〉)。その場合は両方の出典を併記し、GA 一覧表を正とします。最も体系的な一次情報は Feature readiness at GA(GA/プレビュー一覧表) です。

ハイライト(SI 選定観点の要点)

  • 新ポータルは GA、ただし機能単位で GA / プレビューが混在。 Feature readiness at GA の表(2026-08-14 版)が唯一の体系的な一覧。Operate(コントロールプレーン)の大半・Monitoring・Workflows・Memory・AI Gateway 等はプレビュー継続。Quota・プロジェクト詳細は新設の Manage セクション(GA)に移った。
  • Agent Service はサービスとして GA(Responses API ベースの v2)。hosted agents の初期プレビュー基盤は 2026-08-20 でサポート終了済(未移行なら再デプロイ)、ビジュアル Workflows はプレビューのまま 2026-12-01 廃止で Microsoft Agent Framework へ誘導。一方 2026-08 には Autopilot(Agent 365 連携、hosted 専用。ステータス要確認)・長時間実行 hosted agents(preview)・Skills / private skill catalog(preview)・Agent optimizer の prompt agent 対応(ポータル、preview)が追加され、「GA だが足元が動いている」状態は継続。
  • ハブベースプロジェクト(classic)は廃止日未発表のレガシー扱い。 新規投資は Foundry プロジェクトに集中と明言。classic にしか残っていないのは prompt flow(2027-04-20 廃止予定)・serverless API デプロイ・Language の CLU / CQA / カスタム NER・Content Understanding のカスタム作成等(PII・言語検出・TA4H・CU の一部 prebuilt は新ポータルにプレイグラウンドあり)で、マネージドコンピュートは新ポータルに対応済み(パブリックプレビュー)。
  • CLI は一級市民ではない。 専用の az foundry は存在せず、リソース管理は az cognitiveservices(GA。CMK・NSP・Managed VNet は CLI 手順あり)、エージェント開発・評価は azd 拡張(レジストリ表記は Beta)、それ以外の多くの機能は「ポータル + SDK/REST のみ」でドキュメントに CLI 手順がない。2026-08 以降はコーディングエージェント経路(Foundry Skill / Foundry MCP Server〈preview、79 ツール〉/ Foundry Canvas〈preview〉/ DevPack)が公式手段として整備されつつある。
  • Claude(Anthropic)が 2026 年に本格参入。 「Hosted on Azure」形態の claude-opus-5 / sonnet-5 / opus-4-8 等は GA + Data Zone (US) 対応(Fable 5.1 / Mythos 5.1 は Preview)。2026-08-17 に Structured outputs / Web search / Web fetch / Tool search / MCP connector(Beta)も Hosted on Azure で利用可に。ただし Anthropic SDK + Marketplace 課金 + Foundry 組み込みコンテンツフィルター非適用という独自制約は継続。
  • GPT-6 Astra(gpt-6-astra)が 2026-09-03 に GA。 Standard / Provisioned × Global / US Data Zone のみで EU Data Zone・Regional・Batch なし、tool calling は Responses API 必須。EU データ境界が要件の案件は gpt-5.6 系(2028-01-11 まで)で設計する。リタイア日はリタイア表 2026-09-02 版に未掲載。
  • 確定済みの廃止日程が多数(下表)。移行設計を伴う提案では必読。

更新運用ガイド(定期更新の手順)

推奨頻度: 月1回(Microsoft の What's new が月次更新のため)。Ignite(11月)・Build(5月)直後は必ず更新。

  1. 一次情報の差分確認(下記ウォッチリストを上から順に)
    • What's new in Microsoft Foundry — 月次の新機能・ステータス変更
    • Feature readiness at GA(GA/プレビュー一覧) — 機能別ステータスの最重要ページ
    • Model retirement schedule — モデルのリタイア日
    • Microsoft Foundry Blog — 発表の背景・詳細。月次まとめ記事「What's new in Microsoft Foundry」は 2026 年 6 月号(2026-07-07 公開)が最後で 7・8 月号は未発行(2026-09-07 時点)。以降は個別記事(例: Claude 5 機能 2026-08-17、Content Understanding 2026-08-12)と learn 側 What's new で追う
    • リージョン別 feature availability
  2. 各カテゴリ MD の該当行を更新(ステータス変更・新機能追加・廃止済み行の整理)。出典 URL も再確認し、リンク切れ(ドキュメント再編)があれば新 URL に差し替える。
  3. 各ページ冒頭の「最終更新」日付を更新し、本ページの更新履歴に1行追記する。
  4. HTML を再生成: リポジトリルートで python3 docs/survey/tools/md2html.py features を実行(引数なしなら architecture も含めて全ビルド)。
  5. 生成 AI に更新作業を依頼する場合は、本ページと対象カテゴリ MD を読ませた上で「出典 URL を WebFetch で再確認し、ステータス変化のみ差分更新。推測でステータスを書かない」ことを指示する。2026-09-07 の更新で効いた手順: 親が一次情報 3 本(What's new / GA 一覧表 / リタイア表)を先に取得してスナップショット化 → カテゴリごとに 1 エージェントを並列起動し「担当 MD のみ編集・README は親が統合」と役割分担 → 各エージェントは表や日付を WebFetch の要約に頼らず curl で生 HTML から抽出(要約モデルは表を取り違える)→ 完了報告を「訂正 / 追記 / 期限到来 / 変化なし / README 波及 / 他ドキュメント波及 / URL 変更 / 要確認」の 8 項目で統一。
