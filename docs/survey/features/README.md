## ステータス凡例

| 表記 | 意味 |
| --- | --- |
| GA | 一般提供(General Availability)。SLA・サポート対象 |
| パブリックプレビュー | 公開プレビュー。SLA なし・仕様変更あり得る。本番利用は原則非推奨 |
| 限定プレビュー | 申請制・招待制のプレビュー(limited access / gated) |
| 非推奨 | Deprecated。廃止日が予告されている(新規利用を避ける) |
| 廃止 | Retired。利用不可 |
| 要確認 | 公式ページ上にライフサイクル明記が見つからなかったもの(確認した URL を併記) |

**注意:** 公式ドキュメント間でステータス表記が揺れている機能があります(例: **Toolbox**〈GA 一覧表=GA / 旧ブログ=public preview → 7・8 月号ブログで GA 明言し解消。ただし prompt agent への展開はプレビュー〉、**Tool search**〈Azure ブログ 2026-09-24=GA / Learn=preview〉、**Voice Live**〈API 単体=GA / GA 一覧表の Agents 面=Preview / 7・8 月号ブログ=hosted × Voice Live は GA〉、**Content Understanding**〈GA 一覧表=classic 必須 / 新ポータルにプレイグラウンドあり〉、**Trace Replay**〈GA 一覧表=GA / 記事見出し=preview〉、**Agent optimizer**〈GA 一覧表=Limited preview / 記事=preview〉)。その場合は両方の出典を併記し、GA 一覧表を正とします。最も体系的な一次情報は [Feature readiness at GA(GA/プレビュー一覧表)](https://learn.microsoft.com/en-us/azure/foundry/concepts/general-availability) です。

## ハイライト(SI 選定観点の要点)

- **新ポータルは GA、ただし機能単位で GA / プレビューが混在。** [Feature readiness at GA](https://learn.microsoft.com/en-us/azure/foundry/concepts/general-availability) の表(ms.date 2026-08-14 のまま 2026-09-23 に更新され **Routines が Preview → GA**)が唯一の体系的な一覧。Operate(コントロールプレーン)の大半・Monitoring・Workflows・Memory・AI Gateway 等はプレビュー継続。Quota・プロジェクト詳細は新設の **Manage** セクション(GA)に移った。
- **Agent Service はサービスとして GA**(Responses API ベースの v2)。hosted agents の初期プレビュー基盤は 2026-08-20 でサポート終了済(未移行なら再デプロイ)、ビジュアル Workflows は**プレビューのまま 2026-12-01 廃止**で Microsoft Agent Framework へ誘導。一方 2026-08 には **Autopilot(Agent 365 連携、hosted 専用。ステータス要確認)・長時間実行 hosted agents(preview)・Skills / private skill catalog(preview)・Agent optimizer の prompt agent 対応(ポータル、preview)**が追加され、「GA だが足元が動いている」状態は継続。**2026-09 には GA 化の第 2 波**: Routines(GA 一覧表+公式ブログ 2026-09-24。利用不可は UK West / Switzerland West / **Japan West** / UAE North / Norway East の 5 リージョンのみに拡大)・A2A(v1.0 の `a2a` 型。v0.3 / `a2a_preview` はプレビュー)・Tool search(Azure ブログ 2026-09-24 は GA、Learn は preview 表記のまま)。同時に **Voice agents(`kind: voice`)・hosted agent の network egress controls・Foundry insights** がプレビューで追加され、Autopilot は公式ブログ(2026-06-03)で public preview と判明(Learn はラベルなし)。2026-09-28 には **hosted agent のユーザー委任アクセス(アプリ管理の OBO+`x-client-*` ヘッダー転送)**の公式手順と M365 公開のトラブルシューティングページが追加された(詳細は [03](./03-agent-service.md))。
- **ハブベースプロジェクト(classic)は廃止日未発表のレガシー扱い。** 新規投資は Foundry プロジェクトに集中と明言。classic にしか残っていないのは **prompt flow(2027-04-20 廃止予定)**・serverless API デプロイ・Language の CLU / CQA / カスタム NER・Content Understanding のカスタム作成等(PII・言語検出・TA4H・CU の一部 prebuilt は新ポータルにプレイグラウンドあり)で、**マネージドコンピュートは新ポータルに対応済み**(パブリックプレビュー)。
- **CLI は一級市民ではない。** 専用の `az foundry` は存在せず、リソース管理は `az cognitiveservices`(GA。CMK・NSP・Managed VNet は CLI 手順あり)、エージェント開発・評価は azd 拡張(レジストリ表記は Beta)、それ以外の多くの機能は「ポータル + SDK/REST のみ」でドキュメントに CLI 手順がない。2026-08 以降は**コーディングエージェント経路(Foundry Skill / Foundry MCP Server〈preview、79 ツール〉/ Foundry Canvas〈preview〉/ DevPack)**が公式手段として整備されつつある。**Foundry Dev Pack は 2026-09-15 に正式発表**(`winget install Microsoft.FoundryDevPack` 等のワンコマンドで az / azd / Foundry 拡張 / Skill / VS Code 拡張 / Canvas を一括導入。7・8 月号時点の版は 0.1.3 preview)。
- **Claude(Anthropic)が 2026 年に本格参入。** 「Hosted on Azure」形態の claude-opus-5 / sonnet-5 / opus-4-8 等は GA + Data Zone (US) 対応(Fable 5.1 / Mythos 5.1 は Preview)。2026-08-17 に Structured outputs / Web search / Web fetch / Tool search / MCP connector(Beta)も Hosted on Azure で利用可に。**2026-09-22 に `claude-opus-5-5`、2026-09-28 に `claude-sonnet-5-5` が追加**(いずれも v1・v2 とも GA、US Data Zone 対応。sonnet-5-5 の Hosted on Azure × Global Standard はリージョン表に行がなく要確認)。ただし Anthropic SDK + Marketplace 課金 + Foundry 組み込みコンテンツフィルター非適用という独自制約は継続。
- **GPT-6 系: Astra(`gpt-6-astra`)が 2026-09-03 に GA、Sol / Luna(`gpt-6-sol` / `gpt-6-luna`)が 2026-09-22 に GA。** Astra の当初制約(tool calling は Responses API 必須、temperature 等非対応)は **2026-09-11 のドキュメント更新で撤廃**。EU Data Zone は **Sol / Luna は対応**、Astra は region 表が US のみ・2026-09-22 ブログは EU 対応と記載で**要確認**。3 モデルとも Regional・Batch なし。EU データ境界が要件の案件は Sol / Luna か gpt-5.6 系(2028-01-11 まで)で設計する。リタイア日はリタイア表 2026-09-21 版に未掲載。**2026-09-01 以降ローンチのモデルは Data Zone / Regional に価格プレミアムが掛かる**(詳細は [02](./02-models.md))。
- **確定済みの廃止日程が多数**(下表)。移行設計を伴う提案では必読。
