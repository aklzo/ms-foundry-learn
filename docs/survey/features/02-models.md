## 概要

モデルカタログ(10,000+ モデル。foundry-models-overview 2026-07-28 版は「over 10,000 models、月約 50 モデル追加」。初版の 1,900+ は旧記載)、モデルファミリ別の提供状況、デプロイタイプ、Model router、モデルライフサイクル、ファインチューニング、Foundry Local を扱う。カタログは「**Models sold by Azure(Azure Direct)**」(Microsoft がホスト・販売、MS サポート・SLA・Responsible AI 審査付き)と「**Models from partners and community**」(第三者提供、Azure Marketplace 課金)の2区分で整理される。

## 補足ノート(SI 判断に効く要点)

- **⚠ Fireworks 系モデルは予告期間が 15 日しかない**: リタイアスケジュールに Important として「**Fireworks models on Standard (Per-Token) inference offerings are subject to a 15-day notice period prior to model retirement**」と明記。標準ライフサイクル(GA は 60 日前通知)と比べて極端に短く、`FW-*` 系(GLM / Kimi / Qwen / MiniMax / DeepSeek の Fireworks 版)を本番の必須経路に置くとガバナンス上のリスクになる。掲載上のリタイア日は 2027-07-01 だが、この予告条項が優先する。
- **日本語モデル**: **NTT Data の `tsuzumi-7b` は 2026-08-31 に期限到来(後継 `tsuzumi2`)**。retirement schedule 2026-09-02 版では Legacy 表記のまま、models-from-partners 2026-09-01 版にも掲載継続(hub-based プロジェクト必須)で「retired」の明示は未確認。日本語特化モデルを検討する案件では後継への切替を前提にする。
- **Claude の位置づけ**: Claude は「Models sold by Azure」ではなく Marketplace 経由のパートナーモデル。ただし「Hosted on Azure」形態が登場し opus-5 / opus-4-8 / sonnet-5 / haiku-4-5 は Azure 基盤で GA + Data Zone (US) 対応まで来ており、「パートナーモデルはデータ所在が弱い」という従来の前提が変わっている。SDK は Azure OpenAI SDK ではなく **Anthropic SDK(AnthropicFoundry)+ Entra ID** という点が実装上の分岐点。2026-08-17 以降は Structured outputs / Web search / Web fetch / Tool search / MCP connector(Beta)も Hosted on Azure(US Data Zone 含む)で使え、「エージェント機能のために Anthropic 側ホスティングを選ぶ」必要はほぼ消えた。ただし両形態ともデータ処理者・SLA 提供者は Anthropic で、コンテンツ安全は Anthropic 側の安全システムのみ(Foundry 組み込みフィルターなし)。
- **serverless API deployments は実質レガシー**: classic 専用記事となり「Foundry resources への standard deployment を推奨」と明記。新規設計では選ばない。
- **ドキュメント間の齟齬**: 初版で指摘した Claude のライフサイクル表記の食い違いは schedule 2026-09-02 版で GA 表記に統一され解消。現在残る揺れは音声系(`gpt-4o-transcribe` 系・`tts-hd`: sold ページ Preview / schedule GA)、`gpt-oss-120b`(sold Preview / schedule GA)、`gpt-realtime-2`(schedule は 2026-08-31 リタイア / sold 2026-09-04 版に掲載継続)、`Mistral-Large-3`(初版 GA → 両ページとも Preview)。本番採用時は retirement schedule 側の日付を確認する。
- **GPT-6 Astra(2026-09-03 GA)は EU Data Zone なし**: Standard / Provisioned × Global / US Data Zone のみ(Regional・Batch もなし)。EU データ境界が要件の案件では gpt-5.6 系など既存モデルで設計する。リタイア日は 2026-09-02 版 schedule に未掲載。
- **ページ不在**: 新ドキュメント側の `/azure/foundry/concepts/fine-tuning-overview` は 404(FT 概要は `/azure/foundry/openai/how-to/fine-tuning` と classic 側に分散)。
