## 概要

Foundry リソース・プロジェクトのモデル、新旧ポータルの関係、コントロールプレーン(Operate)、RBAC・ネットワーク・暗号化・ポリシーなどのガバナンス機能を扱う。**新 Microsoft Foundry ポータルは GA 宣言済み**(「The new Microsoft Foundry portal is generally available (GA).」)だが、GA はコアシナリオ範囲であり、Operate(コントロールプレーン)の大半など一部機能はプレビュー継続である(出典: https://learn.microsoft.com/en-us/azure/foundry/concepts/general-availability )。

## 補足ノート(SI 判断に効く要点)

- **リソースモデルは連続性重視**: 改称・新ポータル化されても ARM 上は `Microsoft.CognitiveServices/accounts` のままで、既存の Azure Policy / RBAC / ネットワーク構成資産がそのまま効く。AOAI からのアップグレードは kind 変更のパッチ操作(非破壊)で、ロールバック手段も提供。
- **ハブベースの終息は「投資停止」段階**: 廃止日は未発表だが、新規投資は Foundry プロジェクトに集中と明言され、classic ドキュメントは NOINDEX・更新周期 365 日。classic 側にしか無いのは **prompt flow(2027-04-20 廃止予定)**・serverless API デプロイ・Azure Language 等で、**マネージドコンピュートは新ポータル側に移った**(2026-07 時点でパブリックプレビュー)。「classic を残さないと機能が足りない」という論拠は年々弱くなっている。
- **表記揺れへの注意**: hosted agents は navigate-from-classic で「GA」、configure-private-link 内では「hosted (preview) agents」と記載が混在。RBAC ロール名も改名ロールアウト中のため、IaC/スクリプトではロール ID(GUID)指定が公式推奨。ポータルのナビも再編中で、旧「Operate > Admin」は **Manage** ボタン(Quota / AI Gateway / Project details / Resource details / Users / Connected resources)に移動(2026-06〜08 の各ページ)。
- **CMK は「リソースに設定すれば全部暗号化」ではない**(2026-08 新設の適用範囲表): Agent Service の会話履歴・vector store は **BYO ストレージ(Standard setup)でなければ CMK 対象外**。データ主権要件で CMK を求められる案件は Standard setup が前提になる。**さらに hosted agent は BYO でも Partial**(セッションの `$HOME` はプラットフォーム管理ストレージで CMK 不可・30 日保持 — 2026-09-26 確認)なので、CMK 必須案件で hosted agent を使う場合は `$HOME` に機密データを残さない設計が要る。
- **閉域の選択肢は 4 系統**: Private Link(インバウンド)/ BYO VNet 注入 / Managed VNet(2026-05 GA)/ **NSP(GA)**。ただし hosted agent のエンドポイント自体は閉域構成でも公開アドレス。**補完策として hosted agent 専用の network egress controls(2026-09-24 プレビュー)**が加わったが、サンドボックス内プロキシによる宛先制御で FW の代替ではない。加えて HA/DR は「Foundry 自体に自動フェイルオーバー・DR はない」と明記( https://learn.microsoft.com/en-us/azure/foundry/how-to/high-availability-resiliency 2026-07-13 版。2026-09-21 版でも同記載)で、Standard setup の Cosmos DB / AI Search / Storage の冗長化・バックアップは顧客責任。
- **2026-09-26 再検証の要点**: hub 廃止日は依然未公表 / RBAC に `Cognitive Services Usages Reader`(サブスクリプションスコープ)の例外推奨 / CMK 表が Prompt・Hosted に分割 / 接続の Microsoft Fabric がポータル作成可に / BYO VNet は RFC 6598 も可 / BYO リソース宣言が capability settings(プレビュー)へ移行中 / hosted agent の egress controls(プレビュー)新設。
